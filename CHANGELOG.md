# Changelog

This file records repository version objects. An entry is not a production-release claim: signing, distribution, physical qualification, provider integration, pilot acceptance, and store approval remain separate authorities.

## [0.2.0+2] - 2026-09-09

### Added

- Distributed mobile edge runtime with typed policy, decision-lease, audit, device-effect, model, realtime, capability, Skill, Memory, MCP, Codex-worker, qualification, and release-evidence boundaries.
- Android and iOS Even G1 companion paths with dual-leg authority, generation fencing, bounded writes, LC3 processing, speech boundaries, and source-level platform tests.
- Exact-head seven-job CI, source SBOM/provenance, history scanning, native sanitizers, module ownership, module handoff, and external-evidence validation.

### Changed

- Canonical user-visible product identity is Hepta Glasses while inherited Dart and native source namespaces remain explicit compatibility identifiers pending one atomic migration.
- Model, speech, mutation, capability, and memory integrations fail closed unless their authenticated production dependencies are composed.
- G1 packet and mutation-authority wire contracts use strict closed-world parsing and cross-language conformance fixtures.
- Closed pull requests may cause GitHub's historical workflow-run `pull_requests` convenience projection to become empty. Baseline verification now derives only that exact empty form from the independently frozen PR plus exact run branch, event, commit, tree, workflow, and terminal status; malformed or conflicting non-empty projections fail closed.

### Security

- No provider master key, OAuth refresh token, signing key, unrestricted shell, or test-only mutation authority is admitted into the consumer mobile release surface.
- Timeouts after a possible side effect remain indeterminate and require authoritative reconciliation rather than blind replay.
- Historical CI identity no longer depends on a mutable GitHub association projection while all immutable commit, tree, job, Artifact, review, CODEOWNERS, and timestamp checks remain mandatory.

### Qualification ceiling

This repository version is a source candidate. It is not a signed, physically qualified, pilot-qualified, store-approved, or released product.
